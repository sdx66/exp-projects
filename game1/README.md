# Game1
This is a tower defense game written in Python 3 and it will include many features.
## Usage
This version uses 3.11.9. Other Python 3 versions may also work, but they are not guaranteed.
You need to install some packages to run this game. They are:
```text
raylib==6.0.1.0
cffi==2.1.1
pycparser==3.0
```
Or you can install them from requirements.txt.
```bash
pip install -r requirements.txt
```
Then run the game in one of two ways:
1. Start with the seed input screen:
    ```bash
    python main.py
    ```
2. Skip the seed screen and provide an integer seed directly:
    ```bash
    python main.py 42
    ```
Other versions of these packages may work, but they are not tested.
## Note
This is a very early version, so it is quite simple and may be boring.
